3. Security requirements

* Are mandatory requirements explicitly documented?
* Are requirements mapped to architecture components?
* Are control responsibilities assigned?
* Are implementation constraints documented?
* Are security requirements traceable to validation evidence?

Completion principle

A security architecture decision should be understandable, traceable, and accountable throughout the system’s lifecycle.

If nobody owns the decision, the risk has not been properly governed.
